# BED-AND-BREAD-
Bed & Bread
Bed & Bread is a social-impact platform designed to help homeless children and elderly people find nearby shelters, orphanages, old-age homes, food support, and employment opportunities.

Features
Nearby shelter finder using Google Maps API
FoodShare donation system
Donation management
Rewards and badges
Employment opportunities
AI chatbot assistant
Modern dark aesthetic UI
Tech Stack
React
Tailwind CSS
Google Maps API
Google Places API
Vite
Objective
To create a compassionate and technology-driven ecosystem that connects homeless individuals with safe shelter, food, and community support systems.
